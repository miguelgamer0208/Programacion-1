# Programación 1

Este repositorio contiene los programas y ejercicios desarrollados durante la materia de Programación 1.
Los ejercicios están organizados por temas, y cada programa se encuentra en su propia carpeta.
Los ejercicios parecidos, mejoras o del mismo teman algunos de estos estaran en una misma carpeta por sus similitudes 

## Requisitos
Tener instalado Python 3.9 o superior, y instalar las dependencias (en caso de fallos) y opcionalmente, usar un programa como Visual Studio Code para mayor Facilidad

## Cómo ejecutar los programas

Por medio de Terminal:
Escribe `Ubicacion Archivo/Nombre del Archivo.py` o `.pyw`.

En caso de no usar una IDE, puedes usar:

`python3 Ubicacion Archivo/Nombre del Archivo.py`

Por ejemplo:
```bash
python3 Programas/Juego del Gato (Terminado)/JuegoDelGato.pyw
```

## Ejemplo de Entrada y Salida de un programa
